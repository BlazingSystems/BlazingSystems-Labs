# Blaze Ultimate Optimizer v1.0 — Preview

This is the **unchanged first preview build**, published for testing on low-spec Windows computers before further development. It has NOT yet been validated on real Windows hardware; use at your own risk.

## Download

- [Standalone Windows x64 EXE](./BlazeUltimateOptimizer.exe) (67,584 bytes)
- [Complete source + EXE ZIP](./BlazeUltimateOptimizer_CompletePackage.zip) (41,826 bytes)

## How to test

1. Download and run `BlazeUltimateOptimizer.exe` on an existing **x64** Windows 10/11 installation. This build is **not** ARM-native or Linux-compatible.
2. Run **1-CLICK DIAGNOSE** first and review the findings.
3. Optionally try **DIAGNOSE + SAFE FIX** after checking the report and backing up important data.
4. Report crashes, incorrect detections, unexpected changes, and before/after performance to guide the next version.

**This preview does not implement the requested future Advanced Risk Mode or a 3-second countdown.** It is not intended as a system-core disabling utility.
