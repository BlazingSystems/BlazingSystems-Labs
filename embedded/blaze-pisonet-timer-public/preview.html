Public edition

The earlier private build used embedded MP3 payloads and a reusable default Wi-Fi password. This public continuation removes the media payload, generates per-device credentials, and keeps only generic timer/relay/display behavior.

Hardware scope

Coin input, two relay outputs, passive buzzer, TM1637 display, and an ESP8266-hosted settings page. Hardware validation is still required before real deployment.
