# Engineering Lab Notice

Projects in this repository are development-stage engineering work.

Public source is intentionally separated from private deployment material. The repository does not include real client records, employer records, production Wi-Fi credentials, router backup archives, private cryptographic keys, or model weights.

Recovered projects may be represented by a **public-safe derivative** while the unmodified source remains in private storage. A derivative should document material changes such as removed credentials, omitted media payloads, synthetic sample data, or disabled proprietary integrations.

Employer/client material, proprietary forms, private credentials, and unlicensed third-party binaries are intentionally kept outside GitHub rather than placed on a supposedly hidden branch of a public repository.

Hardware-dependent projects require independent electrical and functional validation. Networking examples should be adapted with fresh credentials and environment-specific values before deployment.
