# BlazeFM third-party components

BlazeFM 1.1.0 uses small protocol libraries from Maven Central:

- Apache Commons Net 3.11.1 — FTP client support — Apache License 2.0.
- jcifs-ng 2.1.9 — SMB/CIFS client support — LGPL.
- SLF4J NOP 1.7.36 — logging backend used with jcifs-ng — MIT License.
- mwiede JSch 2.28.7 — SSH/SFTP client support — BSD-style license.

Android platform APIs provide the local filesystem, Storage Access Framework, media preview and package-management integration.
